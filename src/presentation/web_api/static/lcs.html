О персонализации помощника

Когда бот получает ваш профиль, он может уточнять ответы с учётом вашего курса и факультета. Например, первокурснику-иногородному он расскажет про приоритет при заселении в общежитие, а студенту на платном — про рассрочку и скидки.

Важно: данные используются только для персонализации ответов в рамках этого сеанса. Это демонстрационная версия — реальная интеграция с ЛКС МИРЭА в разработке.
